# VibePrompt KR (바이브프롬프트 한국어판)

> **바이브 코더(Vibe Coders)를 위한 한국어 UI 레이아웃 프롬프트 & Tailwind CSS 스니펫 라이브러리**  
> 원본 사이트: [https://vibeprompts.dev/](https://vibeprompts.dev/) 전수 정제, 한국어 현지화 및 기능 고도화 프로젝트

---

## 🌟 프로젝트 소개
**VibePrompt KR**은 현대적인 웹 개발과 생성형 AI 코딩(Claude, Cursor, v0, Bolt 등) 환경에 맞춰 엄선된 **15개 카테고리, 286개 UI 레이아웃 프롬프트**를 전수 한국어로 번역하고, 인터랙티브 실시간 미리보기 및 원클릭 복사 기능을 제공하는 웹 애플리케이션입니다.

---

## ✨ 주요 기능 및 개선사항

### 1. 286개 전수 고품질 한국어 현지화 & 데이터 정제
- **미번역 항목 0건 달성**: 286개 전 항목의 제목(`titleKo`), 설명(`descKo`), 프롬프트 본문(`promptKo`)을 실무 프론트엔드 UI/UX 용어로 전수 번역 완료.
- **Cloudflare 이메일 난독화 100% 복구**: 스크래핑으로 인해 깨져 있던 51개 스니펫의 `[email protected]` 마크업을 정상 이메일로 완전 복원.
- **JSON 번들 최적화 (`3.75MB` → `2.1MB`)**: 중복 필드를 제거하고 고유 인터랙티브 스크립트를 깔끔히 분리.

### 2. 살아있는 인터랙티브 프리뷰 (143개 JS 동작 지원)
- OTP 자동 포커스 이동, 비밀번호 강도 측정기, 탭/아코디언 전환, 계산기 등 **143개 컴포넌트의 실제 동작 JavaScript**가 프리뷰 iframe 내부에서 완벽하게 동작합니다.
- `ResizeObserver` 연동으로 컴포넌트 크기에 따라 iframe 높이가 부드럽게 자동 조절됩니다.
- **Pretendard 한글 폰트 토글**: 프리뷰 화면에 한국어 폰트가 적용된 모습을 실시간으로 비교해볼 수 있습니다.

### 3. 생산성을 극대화하는 바이브 코딩 기능 (신규)
- **카드 원클릭 퀵 복사 (Quick Copy)**: 모달을 열지 않고도 메인 화면 카드에서 바로 한국어 프롬프트를 복사할 수 있습니다.
- **즐겨찾기 (`★` 북마크)**: 자주 쓰는 컴포넌트를 북마크하고 사이드바 상단 `★ 즐겨찾기` 필터로 모아볼 수 있습니다 (`localStorage` 자동 저장).
- **모달 키보드 내비게이션**: 모달이 열린 상태에서 키보드 `←` / `→` 방향키로 이전·다음 컴포넌트를 빠르게 탐색할 수 있습니다.
- **프롬프트 커스터마이저 (Prompt Customizer)**:
  - 프레임워크 선택: `HTML (기본)` | `React (Next.js + Lucide)` | `Vue 3`
  - 원클릭 지시어 토글: `🇰🇷 한국어 UI 텍스트로 생성`, `🌙 다크 모드 지원`
- **통합 랜딩페이지 프롬프트 장바구니 (Prompt Cart)**:
  - 여러 섹션(예: 네비게이션 + 히어로 + 벤토 + 요금제 + 푸터)을 장바구니에 담으면, 일관된 디자인 시스템의 전체 랜딩페이지 제작용 **마스터 프롬프트**를 한 번에 생성·복사할 수 있습니다.

## 🚀 로컬 실행 방법
별도의 빌드 도구 없이 브라우저에서 바로 실행하거나, 내장 로컬 웹 서버로 확인할 수 있습니다.

```bash
# Python 내장 서버로 실행
python3 -m http.server 8000

# 브라우저에서 접속
http://localhost:8000
```

---

## 🛠️ 단일 소스 빌드 파이프라인
데이터(`data/prompts.json`)를 수정한 후 빌드 스크립트를 실행하면 `index.html`의 카드 그리드, 검색 인덱스, 카테고리 카운트가 자동으로 동기화됩니다.

```bash
python3 scripts/build.py
```

## 📦 프로젝트 구조
```
vibeprompts-kr/
├── index.html         # 전체 카드 프리렌더링 및 모달 뷰어가 포함된 메인 페이지
├── css/
│   └── app.css        # 레이아웃 스타일, 퀵 액션, 커스터마이저, 플로팅 장바구니 UI
├── js/
│   └── app.js         # 실시간 검색, 즐겨찾기, 장바구니, 모달 뷰어, 리사이징 로직
├── data/
│   └── prompts.json   # 286개 프롬프트 정제 데이터셋 (인터랙티브 JS 분리 보관)
├── scripts/
│   ├── build.py       # prompts.json 기반 index.html 단일 소스 빌드 스크립트
│   ├── clean_and_optimize.py  # CF 이메일 복구 및 JSON 다이어트 스크립트
│   └── localize_prompts.py    # 286개 프롬프트 전수 한국어 현지화 스크립트
├── previews/          # 286개 컴포넌트 미리보기 고화질 이미지 (.avif)
├── favicon.svg        # 파비콘 아이콘
├── og.png             # 오픈그래프(OG) 썸네일 이미지
├── PLAN.md            # 단계별 구현 계획서
└── README.md          # 프로젝트 안내 문서
```
